# 📘 Attendance Management System (C++)

An object-oriented Attendance Management System built using C++.  
This system allows teachers to manage student attendance records and students to view their attendance details through role-based dashboards.

---

## 🚀 Features

- 🔐 Admin authentication for Teacher Dashboard
- 👨‍🏫 Teacher Dashboard
  - Add new students
  - Mark attendance by date
  - View complete attendance records
- 👨‍🎓 Student Dashboard
  - View personal attendance records
  - Attendance percentage calculation
- 📊 Attendance percentage computation
- 🔍 Search functionality
- 💾 File handling for persistent data storage
- 🧠 Structured menu-driven system

---

## 🛠 Technologies & Concepts Used

- C++
- Object-Oriented Programming (OOP)
- STL (vector)
- File Handling (`fstream`)
- Structured Data Modeling
- Menu-driven Architecture

---

## 🏗 System Design

The system is built using:

- `Student` structure to store student details
- `Attendance` structure to store date and presence status
- `AttendanceSystem` class to encapsulate all functionalities
- Dynamic storage using STL vectors
- File-based persistence for saving and loading records
